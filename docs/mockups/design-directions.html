Design directions — moonu look, ore page

Munnadi kuduthadhu plain-a irundhadhu. Yen-nu keezha irukku. Ippo ore sale page-ai moonu vidhamaa pannirukken. Edhu pidikkudho sollunga — adhe look ellaa screen-kum varum.
Yen plain-a irundhadhu
Namma design rule-la ipdi ezhudhirukku —
"accent colour oru screen-ku oru primary button-ku, focus ring-ku mattum. Bill number, per, thalaippu, badge — ellam mai-niram."

Andha rule thappilla. Thagaval nirambiya screen-ku adhu sari. Aana adhu mattum irundhaa screen saambal-nirama, plain-a theriyum.

Sari seiyura vazhi: rule-ai udaikkaadhu — valarthu. Niram thagaval-ai sollanum (stock kammi, expiry, meedhi) — alangaaram-ku illa. Kooda aazham (shadow), idam (spacing), ezhuthu alavu (hierarchy) — moonum niram illaama azhagu tharum.
Moonu direction
A
Dark till — karuppu thirai, periya velli-niram number. Neenda neram paarkka kann valikkaadhu. Modern POS ellam idhu.
B
Light elevated — vellai card, meludhuvaana nizhal, adhigam idam. Sutthama, nambagamaa. Modern software ellam idhu.
C
Warm brand — namma orange/red brand niram mela, karuppu total panel. Namma company-oda adaiyaalam theriyum.
Moonulum ore thagaval, ore UX — scan box, naalu column, periya total, F-key bar. Look mattum vera.
UX-ai onnum maathala. Cursor scan box-la landing, Enter adutha kattam, F1 save, F2 print, meedhi periya ezhuthu — moonu direction-lum ondre. Neenga niram + aazham mattum thernthedukkireenga.

Azhagu engirundhu varudhu — aaru vishayam

Idhu yosanai illa, palaganna pattern. Moonu direction-lum idhe aaru thaan — niram mattum vera.
1 · Aazham (elevation)
→
Border mattum = thattaiyaa. Meludhuvaana nizhal + periya radius = card "mithakkiradhu" madhiri. Oru screen-la moonu nilai podhum: thirai, card, mithakkura panel.
2 · Ezhuthu alavu vithiyaasam
MOTTHAM
₹ 5,147
Subtotal 4,853.76
Ellame 12px-a iruntha edhuvum mukkiyam illa. Mukkiyamaanadhu periyadhaa, meedhi siriyadhaa. 8px label → 30px number = naalu madangu.
3 · Niram = thagaval
Stock 42 Exp 11/26 Stock illa GST 5% Batch
Pachai nalladhu, manjal kavanam, sivappu aabathu, neelam vari. Alangaaram-ku niram illa — oru paarvaiyil puriyaradhukku.
4 · Varisai-ku oru mugam
IR TD SO ← kann pidichukkum
Ezhuthu mattum irundha varisai ellam ondre madhiri. Chinna mudhal ezhuthu kattam varisaikku thaalam tharudhu — thedaama kann pogum.

Nerukkam = malivaana theatrram. Suvasikka idam viduradhu vilaiyuyarndhadhaa theriyum. Aana thagaval-ai kuraikkakoodadhu — adhaan siriya varisai udhavudhu.
6 · Brand — konjam podhum
Namma orange/red ore oru idathula — logo, mukkiyamana button, focus ring. Ellaa idathulum poattaa thalai valikkum. Adaiyaalam venum, sandadi vendaam.

DIRECTIONEDHUKKU SARIKAVANIKKA
A · Dark Restaurant, bar, iravu neram, thodarndhu 8 mani neram Veliccham adhigam-naa thirai theriyaadhu
B · Light Kirana, pharmacy, supermarket, pagal neram Iravu neram konjam pirakaasam
C · Warm Namma brand mukkiyam-naa, sales demo-ku Mela pattai niram thinam paakkanum
Rendume A + B rendaiyum panna mudiyum — oru toggle. Ippove namma tokens-la light/dark irukku.
Neenga sollavendiyadhu
"A pidikkum"  — dark-la ellam panren
"B pidikkum"  — light-la ellam panren
"A + B rendum"  — toggle vechiduven
"C-oda mela pattai + B"  — kalandhum tharalaam
Edhuvum pidikkalanaa adhaiyum sollunga — "innum periya ezhuthu", "pill vendaam", "niram kammi" — ethuvaa irundhaalum. Neenga sollaama code onnum thodamaatten.
